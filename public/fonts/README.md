# Fonts

Place the following `.woff2` files here, downloaded from [Fontshare](https://www.fontshare.com/):

## Gambarino
- `Gambarino-Regular.woff2`

Download: https://www.fontshare.com/fonts/gambarino

## General Sans
- `GeneralSans-Regular.woff2`
- `GeneralSans-Medium.woff2`

Download: https://www.fontshare.com/fonts/general-sans

These are referenced via `@font-face` in `src/styles/global.css`. The site will fall back to system fonts until the files are present.
